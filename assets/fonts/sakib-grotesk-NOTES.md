# Sakib Grotesk 0.4

Custom, newly drawn reconstruction study after the public Söhne Buch specimen by Kris Sowersby / Klim Type Foundry: https://klim.co.nz/fonts/soehne/

This is not the official Söhne font. No commercial font binary or outline was extracted. The local variable web font has 169 glyphs, 162 Unicode mappings and a 400–650 weight range. It has no italic or Arabic; the site uses Schibsted Grotesk for true italic and fallback characters, and Amiri for Arabic. Regular 400 is used for reading.

The font is self-hosted. Its filename is versioned so updates do not reuse an older cached font.
