# Sakib Grotesk 0.4.1

Custom, newly drawn reconstruction study after the public Söhne Buch specimen by Kris Sowersby / Klim Type Foundry: https://klim.co.nz/fonts/soehne/

This is not the official Söhne font. No commercial font binary or outline was extracted. The static Regular web font has 169 glyphs and 162 Unicode mappings. Heavier experimental weights are not ready for use. It has no italic or Arabic; the site uses Schibsted Grotesk for true italic and fallback characters, and Amiri for Arabic. Regular 400 is reserved for large titles. Schibsted Grotesk carries body text and small labels. Synthetic bolding is disabled, so heavier CSS requests resolve to the same Regular outlines.

The font is self-hosted. Its filename is versioned so updates do not reuse an older cached font.
